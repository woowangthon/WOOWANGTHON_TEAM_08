# 마음결 🌿

> **AI 대화를 상담 준비와 전문적인 도움으로 연결하는 청년 정신건강 지원 서비스**

- **프로젝트명:** woowangthon
- **서비스명:** 마음결

## 프로젝트 소개

마음결은 정신건강에 대한 고민이 있지만 상담을 시작하기 어려운 청년을 위한 서비스입니다. AI와 대화하며 자신의 상황과 감정을 정리하고, 이를 **상담 준비 메모**로 만들어 전문가 상담에 활용할 수 있도록 돕습니다. 또한 지역별 상담기관과 정신건강 지원제도 정보를 제공합니다.

## 기획 배경

청년들은 시간·비용 부담, 상담에 대한 심리적 장벽, 기관과 지원제도에 대한 정보 부족 등으로 필요한 도움을 받는 데 어려움을 겪을 수 있습니다.

마음결은 **고민 정리 → 상담 준비 → 도움 찾기**를 하나로 연결하기 위해 기획되었습니다.

## 주요 기능

- **AI 대화:** 상황과 감정을 질문과 답변을 통해 정리
- **상담 준비 메모:** 대화에서 직접 이야기한 내용을 바탕으로 상담 시 전달할 내용 정리
- **상담기관 탐색:** 현재 위치 또는 선택한 지역을 기준으로 상담기관 검색
- **지원제도 조회:** 정신건강 관련 지원사업·바우처의 대상 및 신청 정보 확인
- **대화 기록 관리:** 계정별 대화 저장 및 다시 보기

## 이용 흐름

**상황 정리 → 감정 살펴보기 → 상담 준비 메모 확인 → 상담기관 탐색 → 지원제도 확인**

### 이용 순서

1. 회원가입 후 로그인합니다.
2. AI 대화에서 말투(따뜻하게 / 차분하게)를 고르고 고민을 이야기합니다.
3. 상담 준비 메모를 확인하고 복사하거나 PDF로 저장합니다.
4. 상담기관 찾기와 지원제도에서 필요한 도움을 찾습니다.

## 기술 설계

### 전체 구조

| 구분 | 역할 |
| --- | --- |
| 브라우저 (Next.js, React) | 대화·메모·기관 탐색·지원제도 화면, Supabase 로그인과 데이터 조회 |
| Next.js API Routes (서버) | AI 대화(`/api/chat`), 상담 준비 메모(`/api/summary`), 지원제도 조회(`/api/support-programs`) |
| AI 모델 | 대화 말투에 따라 Gemini 또는 Groq(`openai/gpt-oss-120b`)를 서버에서 호출 |
| Supabase | 회원 인증, 상담기관 테이블(`facilities`), 대화 기록 테이블(`chat_sessions`) |
| 공공데이터포털 | 정부24 공공서비스(혜택) 정보를 서버에서 실시간 조회 |

### AI 대화 설계

- **3단계 대화:** 상황 정리 → 감정 살펴보기 → 상담 준비로 진행하며, 단계마다 별도의 지침을 적용합니다.
- **사용자 동의 기반 단계 전환:** 챗봇이 다음 단계를 제안하고 사용자가 명확히 동의한 경우에만 넘어갑니다. 동의가 불분명하거나 거절하면 현재 단계를 유지합니다.
- **말투 선택:** 사용자가 고른 말투(따뜻하게 / 차분하게)에 따라 서버가 사용할 모델을 정합니다.
- **구조화된 응답:** 모델은 답변과 단계 정보를 정해진 형식으로만 반환하고, 형식이 어긋나거나 중간에 끊긴 응답은 화면에 내보내지 않고 오류로 처리합니다.
- **입력 제한:** 대화 24개, 메시지 1건당 2,000자, 전체 12,000자까지로 제한하고 서버에서 다시 검증합니다.
- **안전 지침:** 즉각적인 위험 신호가 있으면 긴급 도움 안내를 먼저 하고, 진단·치료 판단을 요청하면 마음결이 판단할 수 있는 범위를 안내합니다. 마음 정리와 무관한 요청에는 목록을 제공하지 않습니다.
- **오류 처리:** 모델 사용량 초과(429·503)와 일반 생성 실패를 구분해 처리합니다.

### 상담 준비 메모

- 대화 내용을 서버(`/api/summary`)에서 모델에 전달해 메모를 생성합니다.
- 메모는 사용자가 확인하고 수정해야 하는 참고 자료이며, 복사하거나 PDF로 저장할 수 있습니다.

### 데이터 설계

- **상담기관:** 기관 정보를 Supabase `facilities` 테이블에 적재해 두고, 화면에서 시·도, 시·군·구, 분류로 필터링합니다. 지도 표시용 좌표는 주소를 사전에 변환해 저장합니다.
- **지원제도:** 호출 시점마다 공공데이터포털(정부24 서비스 목록)을 서버에서 조회한 뒤, 마음건강·심리상담 등 관련 키워드에 맞는 항목만 추려 보여 줍니다. DB에 저장하지 않으며 1시간 동안 캐시합니다.
- **대화 기록:** 로그인한 사용자의 대화를 Supabase `chat_sessions`에 계정별로 저장하고, 다시 열거나 삭제할 수 있습니다.

## 서비스 안내

마음결은 전문 상담이나 진료를 **대체하지 않는 상담 준비 보조 서비스**입니다.

AI는 정신질환을 진단하거나 치료·약물 처방을 제공하지 않으며, 생성된 메모는 사용자가 확인·수정해야 하는 참고 자료입니다. 상담기관 운영 여부와 지원제도 신청 조건은 공식 기관에서 다시 확인해야 합니다.

위급한 상황에서는 AI 대화보다 즉각적인 사람의 도움이 우선입니다. 긴급 신고 **112·119**, 자살예방상담전화 **109**를 이용할 수 있습니다.
